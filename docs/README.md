# Uchaaran project context

Start here for the team handoff. Last updated October 16, 2026.

We are designing a Kids Mode experience for Sundar Gutka that helps children practise Gurbani attentively and improve pronunciation against an ustaad's standard. The initial team focus is grades 6 through 8, a visible practice journey, and earned cosmetic rewards.

## What is settled and what is proposed

The challenge brief supplies requirements. The meeting supplies initial team priorities. Detailed product behavior, botanical styling, nature rewards, economy amounts, and screen layouts are proposals for review. Visual inspection confirms layout only. Prototype interactions have been tested; pronunciation model quality has not been validated.

The text in these topic files is the maintained context handoff. The earlier [combined product draft](../outputs/v1-product-and-journey.md) is preserved as the planning artifact from which they were organized. Prefer the topic files for subsequent context updates and keep the combined draft consistent when its scope changes.

## Useful vocabulary

| Term | Meaning in this project |
| --- | --- |
| Uchaaran | Pronunciation, measured against the supplied ustaad standard |
| Ustaad | Expert teacher who provides references, rules, and judgments |
| Gurbani / bani | Sacred text being practised; bani also identifies a selected composition |
| Nitnem | Daily recitation practice described by the challenge |
| Pauri | A stanza-level practice unit; one completed pauri is not a completed bani |
| Pankti | A line selected for recitation |
| Alignment | Matching text words to reference audio or the learner's current voice position |
| Practised | An activity occurred; not a claim of mastery |
| Mastered | Reserved for a reviewed, repeatable skill criterion that is not yet defined |
