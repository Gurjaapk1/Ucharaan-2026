# Japji Sahib illustration source

39 new original PNGs and optimized JPEG counterparts extend the existing Pauri 1 reference to all 38 pauris, plus opening and closing illustrations. Generated with the built-in image tool using `prototype/public/assets/pauri-1-calm.jpg` as the style reference. Exact prompts are in `prompts.json`; `briefs.json` records the initial thematic plan. `generated.json` preserves generation provenance, while `assets.json` records the portable runtime paths and hashes.

Open the published `/art-review.html` gallery for all 40 landscapes. See `docs/20-complete-japji-artwork.md` for usage, source basis, line mapping and review limits. Interpretive cues require educator and Khalis review before production release.
